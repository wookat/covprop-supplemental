# Datasets

No data ships in this repository — all datasets are public. The loaders
search fixed locations controlled by environment variables.

## Electricity markets (epftoolbox format)

Files: `NP.csv PJM.csv BE.csv FR.csv DE.csv` — hourly day-ahead price with
two exogenous forecasts, from the epftoolbox dataset release:
<https://github.com/jeslago/epftoolbox> (Lago et al., 2021).

Load path: `$EPF_DIR/<MARKET>.csv`, defaulting to `~/epf/<MARKET>.csv`
(`code/core/data.py::load_market`). The loader reads the columns after the
header as `[cov1, cov2, price]`.

## Long-horizon benchmarks (LTSF format)

Files: `ETTh1.csv ETTm1.csv ETTh2.csv ETTm2.csv weather.csv electricity.csv`
— standard multivariate CSVs from the Informer/Autoformer releases:
ETT: <https://github.com/zhouhaoyi/ETDataset>;
weather/electricity: <https://github.com/thuml/Autoformer>.

Load path: `$LTSF_DIR/<name>.csv`, defaulting to `code/datasets/<name>.csv`
(`code/covprop_r1.py`, `DATA` constant). Target is the last channel (OT);
for the wide datasets (weather, electricity) the four channels with the
highest train-split |correlation| to the target serve as covariates.

## Synthetic

SynDeg / SynDeg-hetero are generated by `code/core/syndeg.py` — no download.
